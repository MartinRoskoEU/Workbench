# Workbench

Workbench is a developer-focused addon for World of Warcraft Retail.

It is intended to provide useful in-game tools for developing, testing, and debugging World of Warcraft addons.

## Status

Workbench is currently under development.

## Features

Planned features include:

- Lua console with output
- Quick access to Blizzard developer and debugging tools
- Developer utilities for addon testing and inspection

More features will be added as development progresses.

## Installation

1. Download or clone the repository.
2. Place the `Workbench` folder inside:

   `World of Warcraft/_retail_/Interface/AddOns/`

3. Start World of Warcraft or reload the UI.
4. Enable Workbench in the AddOns menu.

## Compatibility

- World of Warcraft Retail

## Development

Workbench is developed as an open-source World of Warcraft addon.

The project is currently in an early development stage, so its structure and functionality may change.
